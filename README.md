
# Semestrika

### Твой семестр под контролем.

Semestrika — веб-приложение для планирования и контроля
выполнения учебных заданий студентов.

Проект разработан в рамках учебной дисциплины.

## Цель проекта

Создание единого цифрового пространства для организации
учебного процесса, контроля сроков выполнения заданий
и рационального распределения времени студента.

## Основные возможности

- Персональная статистика успеваемости по заданиям.
- Создание, редактирование и удаление учебных заданий.
- Управление учебными дисциплинами.
- Контроль сроков сдачи и статусов заданий.
- Поиск, фильтрация и сортировка.
- Интерактивный учебный календарь.
- Анализ и планирование учебной нагрузки.
- Регистрация и авторизация пользователей.
- Личный кабинет с персональными настройками.
- Разграничение доступа к пользовательским данным.

## Semestrika Radar

Semestrika Radar — встроенный алгоритм анализа
учебной нагрузки на ближайшие семь дней.

На основании сроков сдачи заданий, предполагаемого
времени выполнения и индивидуального дневного лимита
система:

- рассчитывает суммарную учебную нагрузку;
- выявляет перегруженные дни;
- учитывает просроченные задания;
- предупреждает о возможном дефиците времени;
- формирует рекомендуемый план выполнения заданий.

Алгоритм реализован средствами Python без использования
внешних сервисов искусственного интеллекта.

## Структура базы данных

В проекте используются три собственные модели:

- Subject — учебные дисциплины.
- Task — учебные задания.
- StudentProfile — персональные настройки студента.

Для регистрации и авторизации используется
встроенная модель User фреймворка Django.

Связи между моделями:

- User — Subject: один ко многим.
- Subject — Task: один ко многим.
- User — StudentProfile: один к одному.

## Локальный запуск

Инструкция для Windows (CMD).

1. Откройте терминал в корневой папке проекта.

2. Создайте виртуальное окружение:

   ```cmd
   python -m venv venv
   ```

3. Активируйте виртуальное окружение:

   ```cmd
   venv\Scripts\activate.bat
   ```

4. Установите зависимости:

   ```cmd
   pip install -r requirements.txt
   ```

5. Если файл .env отсутствует, создайте его:

   ```cmd
   python -c "import secrets; print('SECRET_KEY=' + secrets.token_hex(50))" > .env
   ```

6. Выполните миграции базы данных:

   ```cmd
   python manage.py migrate
   ```

7. Запустите сервер:

   ```cmd
   python manage.py runserver
   ```

8. Откройте в браузере:

   http://127.0.0.1:8000/

9. Зарегистрируйте новый аккаунт и начните работу.

## Административная панель

Для создания администратора выполните:

```cmd
python manage.py createsuperuser
```

Адрес административной панели:

http://127.0.0.1:8000/admin/

## Тестирование

Для запуска автоматизированных тестов:

```cmd
python manage.py test planner
```

проверяющих авторизацию, разграничение доступа,
CRUD-операции, валидацию, поиск, календарь,
алгоритм Semestrika Radar и персональные настройки.
