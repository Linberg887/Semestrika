
# Semestrika

**Твой семестр под контролем.**

## Описание проекта

Semestrika — веб-приложение для планирования и контроля выполнения учебных заданий студентов.

Проект разрабатывается в рамках дисциплины «Веб-разработка» на первом курсе магистратуры.

## Цель проекта

Создание удобного инструмента для организации учебного процесса и контроля сроков выполнения заданий.

## Планируемый функционал

- Управление учебными дисциплинами.
- Добавление, редактирование и удаление заданий.
- Контроль сроков сдачи.
- Управление приоритетами и статусами заданий.
- Поиск и фильтрация.
- Статистика выполнения заданий.
- Личный кабинет студента.

## Используемые технологии

- Python 3.14
- Django 5.2
- HTML5
- CSS3
- SQLite
- Git

## Локальный запуск на Windows

1. Создать виртуальное окружение:

   `py -3.14 -m venv venv`

2. Активировать виртуальное окружение:

   `venv\Scripts\activate.bat`

3. Установить зависимости:

   `python -m pip install -r requirements.txt`

4. Создать файл .env, если он отсутствует:

   `python -c "import secrets; print('SECRET_KEY=' + secrets.token_hex(50))" > .env`

5. Применить миграции:

   `python manage.py migrate`

6. Запустить сервер:

   `python manage.py runserver`

7. Открыть в браузере http://127.0.0.1:8000/
